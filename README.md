# Планировщик личных задач (Task Planner)

Веб-приложение для управления личной продуктивностью. Позволяет структурировать задачи по категориям и приоритетам, отслеживать дедлайны в формате интерактивного календаря.

---

## Технологический стек

* **Backend:** Python (Flask, Flask-SQLAlchemy, PyMySQL, PyJWT)
* **Frontend:** HTML5, CSS3, Vanilla JS
* **Database:** MySQL
* **DevOps:** Docker, Docker Compose

---

## Основной функционал

* **Авторизация и профиль:** безопасная регистрация и вход пользователей (`PyJWT`, хэширование паролей).
* **Управление задачами (Task CRUD):** создание, редактирование, удаление и смена статусов.
* **Категоризация:** разделение задач по направлениям (Работа, Учёба, Дом) с возможностью назначения иконки.
* **Календарь выполнения:** визуализация задач на сетке месяца/недели.

---

## 🗄 Структура базы данных (MySQL)

### 1. Таблица `users` (Пользователи)

| Поле | Тип | Индексы | Описание |
| :--- | :--- | :--- | :--- |
| `id` | INT | PK, AUTO_INCREMENT | Уникальный идентификатор пользователя |
| `username` | VARCHAR(16) | UNIQUE | Имя пользователя (логин) |
| `password_hash` | VARCHAR(255) | | Хэш пароля для авторизации |

### 2. Таблица `events` (События/Планы)

| Поле | Тип | Индексы | Описание |
| :--- | :--- | :--- | :--- |
| `id` | INT | PK, AUTO_INCREMENT | Уникальный идентификатор события |
| `owner_id` | INT | FK (`users.id`) | Владелец события (внешний ключ) |
| `title` | VARCHAR(67) | | Название события |
| `icon` | VARCHAR(32) | | Иконка или эмодзи события |
| `description` | VARCHAR(1000) | | Подробное описание |
| `start_at` | DATETIME | | Дата и время начала |
| `end_at` | DATETIME | | Дата и время окончания |
| `visibility` | VARCHAR(20) | | Статус видимости (например: public, private) |
